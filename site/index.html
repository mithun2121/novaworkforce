How it works

Clear steps. Reviewable work.

NOVA is early-stage. The current product preview can prepare a mission request and, once configured, send it to a server-side model workflow. A model review is not independent proof of correctness.

Open product preview
  1. Describe the task. Set the objective, constraints and intended output.
  2. Provide information. Use supported text or structured files that you are authorised to share.
  3. Prepare a result. The configured AI workflow returns a structured draft, assumptions and open gaps.
  4. Review and decide. Check the output before using it or taking consequential action.
